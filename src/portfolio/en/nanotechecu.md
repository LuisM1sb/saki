## The project

Nanotechecu is a Chilean brand specializing in the sale and installation of their own proprietary programmable ECUs for the automotive industry.

## What we did

- 🔧 Maintenance of pages, products and site sections
- 🔒 Safe and controlled plugin and theme updates
- 📊 Facebook Pixel and Google Tag Manager setup
- 🚑 Site rescue after a crash caused by plugin conflict
- ⚡ Proactive monitoring to prevent future downtime

## Result

Site stabilized and running without interruptions after the rescue. The client regained full access to their platform, plugins were updated and audited, and tracking via Pixel and GTM allowed them to measure visitor behavior for the first time. The site now operates under ongoing maintenance — no surprises.

## Technologies

- WordPress + custom theme
- PHP / HTML / CSS
- Technical and content SEO
- cPanel-hosted environment
